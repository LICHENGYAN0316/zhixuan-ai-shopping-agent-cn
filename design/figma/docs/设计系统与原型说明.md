# 设计系统与交互原型说明

## 1. 视觉方向

视觉系统继续采用暖白画布、石墨黑主色、铜橙强调色和证据绿状态色。日化领域更新没有改动颜色、字体、间距、圆角、阴影、栅格或页面层级。

## 2. Variables 与 Styles

- 73 个 Variables，分为 Primitive colors、Semantic colors 和 Sizing 三组。
- 语义色覆盖 Canvas、Surface、Inverse、Accent、Success、Warning、Danger、Border、Text、Icon 与 Action。
- 尺寸变量覆盖 spacing、radius 和常用布局间距。
- 11 个文字样式覆盖 Hero、H1–H3、Title、Body、Label 与 Code。
- 3 个阴影样式覆盖 Subtle、Raised 与 Floating。

本次代码更新没有新增、删除或重命名视觉 Token。

## 3. 组件绑定

| 组件集 | 当前日化绑定 |
|---|---|
| LogoMark | “日化智能选品”副标题 |
| Button | 既有主、次、幽灵按钮及禁用状态 |
| Chip | 品类、样本预算、肤质、功效和避开项 |
| Composer | 当前中文日化需求 |
| Requirement Field | 品类、预算、场景、优先指数 |
| Progress Step | 理解需求、检索候选、证据排序、整理依据 |
| Recommendation Card | 商品名、样本价、理由、从六个商品指数中选出的三个指数和证据取舍 |
| Evidence Row | 历史商品字段、需求映射、成分与功效证据 |
| Comparison Cell | 场景、样本预算、核心指数、成分透明/敏感适配 |
| Metric Card | 商品数、样本价完整率、历史信号覆盖率、官方参考数 |
| Feedback Panel | 加载、无结果和数据载入错误 |

## 4. 固定交互路径

### Desktop

欢迎 →（缺预算时进入预算澄清）→ 处理进度 → 推荐结果 → 方案对比 / 推荐依据。

- “查看示例方案”执行默认日化需求。
- 处理进度保留 650、1,320、2,050 ms 阶段更新，并在约 2,800 ms 后按最终 Intent 进入推荐结果或预算澄清。
- 推荐卡可加入对比或进入依据详情。
- 至少选择两个候选后对比按钮可用；最多保留三个。
- 对比页和依据页均有返回路径。
- 顶部导航仍为“智能导购 / 我的方案 / 项目说明”。

### Mobile

- 推荐页只显示当前活动卡片，通过进度点切换候选。
- 对比使用紧凑矩阵，依据页保持返回操作。
- 底部导航仍为“导购 / 方案 / 项目”。
- 720 px 以下启用移动布局；其他既有断点保持 1,180、920 和 390 px。

## 5. 允许与禁止的变化

允许改变：

- 示例需求、商品名和日化品类；
- 商品值、样本价、理由和取舍；
- 属性 Chip 与对比维度的日化语义；
- 项目页实际数据质量指标。

禁止改变：

- 页面顺序、导航层级和主要组件结构；
- CSS 类名、断点、栅格、间距、颜色、字体、圆角和阴影；
- 卡片数量、最多三项对比和三类证据行；
- 键盘提交、预算按钮自动继续、返回、重试、展开/收起和滚动行为；
- 处理页可见四步和计时节奏。

## 6. 当前状态覆盖

- 输入：空白、焦点、已填写、禁用和提交。
- 澄清：当前只实现预算缺失与预算选择。
- 处理：四阶段进行中与完成。
- 结果：Top 3、无满足候选、数据载入失败和重试。
- 对比：不足两项时禁用，2–3 项时可进入。
- 证据：当前品牌官方参考或仅历史标题两类主要状态；行支持展开/收起。
- 豆包：成功或本地降级共用同一可见流程，没有独立错误页。
- 可访问性：可见焦点环、非颜色状态、移动触控目标和减少动效。

当前没有专门的品类、肤质、功效澄清页面，也没有医疗风险状态。

## 7. 数据状态到视觉状态

| 数据状态 | 当前视觉行为 |
|---|---|
| `official_current_reference` | 显示当前品牌官方参考、核实日期和跨市场边界 |
| `historical_title_only` | 显示“依据有限”，不把标题词作为高级结论 |
| `ingredient_list_completeness=full` | 可展示当前完整成分字符串 |
| `ingredient_list_completeness=key_only` | 仅展示关键成分；未知项保持未知 |
| 高级资格不满足 | 检索前排除，可能进入原无结果状态 |
| 豆包缺 Key、超时或失败 | 服务端返回本地 Intent；UI 继续预算澄清或推荐 |

## 8. 实际项目页数据

四张指标卡：

1. 3,497 个去重历史商品；
2. 100.0% 样本价字段完整率；
3. 91.4% 历史销量或评论信号覆盖率；
4. 5 条人工当前品牌官方参考。

五项摘要：3,497 个商品、22 个店铺字段、5 条核实属性、3 个敏感肌资格、4 个成分避雷资格。

## 9. 服务端集成对 UI 的约束

- 浏览器向 `/api/intent` 发送当前需求文本；
- `ARK_API_KEY` 只在服务端读取；
- 请求只包含需求、System Prompt 和严格 Function Schema，不包含商品库；
- 无 Key、6 秒超时或上游失败时自动使用本地解析；
- 不增加登录、密钥输入、模型选择或平台授权界面。

## 10. 证据边界

- 商品目录来自离线历史快照，界面价格为样本价。
- 5 条核实记录均为当前美国品牌页面参考：4 条同名同规格跨市场匹配，1 条系列匹配。
- 当前成分字段是字符串列表；没有监管备案、浓度、禁限用目录或香料过敏原专用字段。
- 关键成分列表不能当作完整配方；只有官方明确“不含”的项目可以支持相应避开判断。
- 品牌声明必须保留声明主体；当前参考不反推历史配方。
- 六个商品指数和需求匹配分只用于展示与排序，不是购买、功效或安全概率。
