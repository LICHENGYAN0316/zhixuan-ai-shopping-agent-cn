# 日化商品离线数据字典

## 1. 当前数据原则

- 商品候选来自离线历史商品快照，不连接实时电商接口。
- 商品对象实际使用 `price`；界面通过 `price_label="样本价"` 说明字段性质。
- 源 CSV、源工作簿、客户编码和订单编码不进入公开仓库。
- `merchant_claim_tags` 和 `title_ingredient_mentions` 来自历史标题规则，只是未核实检索标签。
- 敏感肌、成分避雷和功效资格只来自 5 条人工整理的当前品牌官方参考。
- 这些参考以当前跨市场页面为主，不证明历史中国市场商品使用相同配方。

## 2. 构建入口

```bash
.venv/bin/python scripts/build_daily_catalog.py \
  --beauty-csv "/absolute/path/to/beauty-snapshot.csv" \
  --daily-xlsx "/absolute/path/to/daily-chemicals.xlsx"
```

两个参数均为 required。可选参数包括 `--verified`、`--output-dir` 和 `--public-dir`。

## 3. `public/data/daily-products.json`

当前包含 3,497 个商品对象，每个源商品 ID 保留最新有效快照。

### 3.1 身份、分类与样本字段

| 字段 | 类型 | 实际含义 |
|---|---|---|
| `product_id` | string | 源商品 ID，作为公开稳定主键 |
| `name` | string | 有官方参考时用标准商品名，否则用清洗后的历史标题 |
| `source_title` | string | 清洗活动词后的历史标题，不是未经处理的原始标题 |
| `category` | string | 规则推断或官方参考覆盖后的日化品类 |
| `product_type` | string | 规则推断或官方参考覆盖后的产品类型 |
| `brand` | string | 有参考时为标准品牌；否则实际回退为 `shop_name` |
| `shop_name` | string | 历史快照的店铺字段 |
| `price` | number | 最新有效快照的数值价格字段 |
| `price_label` | string | 固定为“样本价” |
| `sales_count` | number/null | 最新快照的历史销量字段；缺失保留 `null` |
| `review_count` | number/null | 最新快照的历史评论字段；缺失保留 `null` |
| `size_value` | number/null | 从标题首个规格表达提取并统一 kg→g、L→ml |
| `size_unit` | string/null | `g` 或 `ml` 等归一化单位 |
| `historical_data` | boolean | 固定为 `true` |

### 3.2 标题标签

| 字段 | 类型 | 实际含义 |
|---|---|---|
| `merchant_claim_tags` | string[] | 从标题提取的保湿、舒缓、修护、控油等商家功效词 |
| `title_ingredient_mentions` | string[] | 从标题提取的烟酰胺、水杨酸、玻尿酸等成分词 |

以上两个字段未经过产品级官方核实。普通检索可使用，高级敏感肌、成分避雷或核实功效不能仅靠它们放行。

### 3.3 当前官方参考字段

| 字段 | 类型 | 实际含义 |
|---|---|---|
| `evidence_level` | string | `official_current_reference` 或 `historical_title_only` |
| `match_status` | string | `exact_name_size_current_cross_market`、`canonical_series_only` 或 `legacy_unmatched` |
| `formula_market` | string/null | 当前参考页面的市场 |
| `formula_version_label` | string/null | 当前参考与历史记录的版本边界 |
| `formula_checked_at` | string/null | 人工核实日期 |
| `ingredient_list_completeness` | string | `full`、`full_current_reference`、`key_only` 或 `none` |
| `ingredients` | string[] | 当前参考页抄录的完整或关键成分字符串 |
| `normalized_ingredients` | string[] | 有限同义词规范后的成分字符串 |
| `official_formulated_without` | string[] | 当前品牌页明确列出的“不含”项目 |
| `normalized_formulated_without` | string[] | 有限同义词规范后的“不含”项目 |
| `official_skin_types` | string[] | 当前品牌页列出的肤质 |
| `official_concerns` | string[] | 当前品牌页列出的关注点 |
| `brand_claims` | object[] | 品牌声明、声明主体、证据方法、URL 和核实日期 |
| `evidence_sources` | object[] | 来源类型、URL、核实日期和支持字段 |
| `recommendation_eligibility` | object | 基础检索、功效、敏感肌、成分避雷四个布尔值 |

当前商品目录没有监管备案、注册号、禁限用目录、浓度、CAS、成分顺序或香料过敏原专用字段。

### 3.4 运行时联网证据覆盖层

联网证据不会写回 `daily-products.json`。页面请求期间，`applyWebEvidence` 只克隆命中的本地商品并可产生：

| 字段/值 | 含义 |
|---|---|
| `evidence_level=web_public_reference` | 已附加联网来源；不等于品牌官网或历史配方已核实 |
| `match_status=web_source_only` | 证据与本地候选按品牌、类型、名称词项映射，不改变历史商品身份 |
| `source_kind=brand_official_page_web` | 候选品牌与其官网域名白名单同时命中 |
| `source_kind=web_public_reference` | 第三方公开页，只作线索 |

`brand_official_page_web` 与 `web_public_reference` 都只附加来源和 `search_summary_mentions_*` 线索，不写入运行时官方字段，也不提高敏感肌、功效核实或成分避雷资格。联网覆盖层不修改 `price`、`price_label`、历史销量或评论。

### 3.5 展示与排序字段

| 字段 | 类型 | 实际计算 |
|---|---|---|
| `description` | string | 品类/产品类型与历史快照来源说明 |
| `highlights` | string | 有参考时取第一条品牌声明；无参考时说明标题标签未核实 |
| `limitations` | string | 参考记录 notes 或历史标题证据限制 |
| `efficacy` | number | 有功效资格为 0.9；否则按标题标签数量给低权重启发值，不能当作功效事实 |
| `sensitivity` | number | 敏感肌资格为 1，否则为 0 |
| `ingredientTransparency` | number | 完整/当前完整参考为 1，关键成分为 0.55，无成分为 0 |
| `value` | number | 同品类样本价百分位反向分 |
| `popularity` | number | 历史销量百分位；缺失填 0 仅用于数值指数 |
| `reviewSignal` | number | 历史评论百分位；缺失填 0 仅用于数值指数 |

六个指数均限制在 0–1，仅用于界面比较和启发式排序，不是购买、功效或安全概率。

## 4. `data/daily_chemicals/verified_product_attributes.json`

当前有 5 条人工记录，不是通用成分数据库。

### 4.1 顶层字段

| 字段 | 类型 |
|---|---|
| `source_product_id` | string |
| `source_title_match` | string |
| `canonical_brand` / `canonical_product_name` | string |
| `variant` | string |
| `size_value` / `size_unit` | number或null / string或null |
| `category` / `product_type` | string |
| `match_status` | string |
| `formula_market` / `formula_version_label` | string |
| `formula_checked_at` | ISO 日期字符串 |
| `ingredient_list_completeness` | string |
| `ingredients` | string[] |
| `official_formulated_without` | string[] |
| `official_skin_types` / `official_concerns` | string[] |
| `brand_claims` / `evidence_sources` | object[] |
| `recommendation_eligibility` | object |
| `notes` | string |

### 4.2 当前分布

- `match_status`：4 条 `exact_name_size_current_cross_market`，1 条 `canonical_series_only`；
- 成分完整度：2 条 `full`、2 条 `key_only`、1 条 `full_current_reference`；
- 基础检索资格：5；
- 功效资格：4；
- 敏感肌资格：3；
- 成分避雷资格：4。

`ingredient_avoidance=true` 的关键成分记录只对品牌明确 `official_formulated_without` 的项目提供放行证据；不能从关键成分列表中缺少某项就推断不含。

### 4.3 `brand_claims`

每条品牌声明实际包含：

| 字段 | 含义 |
|---|---|
| `claim` | 带“品牌官方称”等归属的中文摘要 |
| `claim_owner` | 当前为 `brand` |
| `evidence_method` | 当前为官方产品页等文字说明 |
| `source_url` | 品牌官方页面 |
| `checked_at` | 人工核实日期 |

### 4.4 `evidence_sources`

每条来源实际包含 `source_kind`、`url`、`checked_at` 和 `supports: string[]`。当前没有页面快照哈希或监管查询记录。

## 9. 当前自动测试

`tests/test_data_pipeline.py` 当前验证：

- 标题活动词清洗；
- 商品快照完全重复去除、最新记录选择和缺失信号保留；
- 工作簿重复、异常日期、数值后缀和孤儿关联处理；
- 3,497 个唯一公开商品与 5 个官方参考；
- 公开商品不含日期、客户/订单字段或活动词；
- `price_label` 固定为“样本价”；
- 六个指数有限且在 0–1；
- 敏感肌资格商品具有官方参考和来源。

`tests/agent.test.ts` 与 `tests/web-search.test.ts` 还验证 17 个通用语义与联网证据用例，包括产品同义词、实体级否定/改口、跨品类及目录缺失分支、中文数字与预算方向、品牌/成分极性、具体核实功效、成分族、肤质排序、联网触发门槛、服务端候选白名单、官网域名分级、第三方降级和搜索摘要不升级硬资格。

当前未自动检查使用真实 Key 的 API 上游联调、manifest 哈希、监管字段、`medical_red_flag` 等医疗风险或浏览器交互。
