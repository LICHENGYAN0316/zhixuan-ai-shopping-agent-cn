# 合成电商数据库数据字典

## 1. 生成原则

- 固定随机种子：`20260828`。
- 固定参考时间：`2026-08-28T09:00:00+10:00`。
- 品牌、型号、用户、评价与行为全部虚构。
- 数据用于模型训练、Agent 测试和产品演示，不用于真实商业决策。
- `data/generated/manifest.json` 保存行数、切分、文件大小与 SHA-256。

运行 `npm run data:generate` 会重建全部 CSV 和 `data/zhixuan_ecommerce.db`。

## 2. products

720 个商品，覆盖笔记本电脑、智能手机、平板电脑、头戴耳机、显示器和键鼠套装。

| 字段 | 类型 | 说明 |
|---|---|---|
| `product_id` | TEXT | 合成商品主键 |
| `category` | TEXT | 6 个 3C 品类之一 |
| `brand` / `name` | TEXT | 虚构品牌与型号 |
| `price` / `original_price` | INTEGER | 当前价与划线价，单位元 |
| `rating` | REAL | 3.5–5.0 的合成评分 |
| `review_count` / `sales_count` | INTEGER | 合成评价数与销量 |
| `stock` | INTEGER | 合成库存 |
| `performance` 等 11 列 | REAL | 0–1 能力分 |
| `release_days` | INTEGER | 距参考时间的上新天数 |
| `description` | TEXT | 商品文档摘要 |
| `highlights` | TEXT | 三个主要亮点 |
| `limitations` | TEXT | 主要取舍提醒 |

能力分：`performance`、`battery`、`portability`、`display`、`camera`、`audio`、`gaming`、`office`、`connectivity`、`quality`、`sustainability`。

## 3. users

2,500 个匿名合成用户，不含姓名、电话、邮箱、地址、账号或任何真实个人信息。

| 字段 | 说明 |
|---|---|
| `user_id` | 合成用户主键 |
| `age_group` | 年龄段枚举 |
| `city_tier` | 城市层级枚举 |
| `price_sensitivity` | 0–1 价格敏感度 |
| `preferred_brand` | 偏好虚构品牌 |
| `preferred_category` | 偏好品类 |
| `primary_use_case` | 主要使用场景 |
| `created_at` | 合成注册时间 |

## 4. queries

8,000 个查询会话。

| 字段 | 说明 |
|---|---|
| `query_id` / `user_id` | 查询与用户主键 |
| `query_text` | 中文自然语言需求 |
| `category` / `use_case` | 目标品类与场景 |
| `budget_min` / `budget_max` | 预算区间 |
| `preferred_brand` | 品牌偏好 |
| `primary_preference` | 核心能力偏好 |
| `pref_*` | 11 维归一化偏好权重 |
| `query_time` | 合成查询时间 |
| `split` | train / validation / test |

## 5. interactions

96,000 条曝光级交互，每个查询 12 个候选。

| 字段 | 说明 |
|---|---|
| `interaction_id` | 交互主键 |
| `query_id` / `user_id` / `product_id` | 关联键 |
| `position` | 模拟曝光位置 |
| `clicked` | 是否点击 |
| `added_to_cart` | 是否加购 |
| `purchased` | 是否购买 |
| `dwell_seconds` | 合成停留时长 |
| `relevance_grade` | 0–3 级相关标签 |
| `event_time` | 事件时间 |
| `split` | 与查询一致的数据切分 |

## 6. reviews

5,000 条合成评价，包括评分、短文本、有用票与时间。文本明确来自模板，不应被当作真实消费者反馈。

## 7. product_fts 与 experiments

- `product_fts`：SQLite FTS5 虚拟表，索引名称、品类、描述、亮点与限制。
- `experiments`：保存实验 ID、模型名、训练/测试查询数、指标 JSON 与生成时间。

## 8. 数据质量检查

`tests/test_data_pipeline.py` 自动检查：

- 行数与预期一致；
- 交互外键无孤儿记录；
- 查询不会跨数据切分；
- 价格、评分、相关等级合法；
- 指标处于 0–1 且模型优于热门度基线；
- manifest 明确声明数据为 synthetic。
