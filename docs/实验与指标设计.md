# 数据质量与覆盖说明

## 1. 为什么不报告推荐准确率

当前日化商品目录没有合法、可归因的用户相关性标签。推荐分由规则与六个商品指数构成，因此项目不报告 Precision、Recall、NDCG、MRR、购买概率或模型相对提升。

当前可验证的是：清洗输入输出是否一致、公开字段是否符合边界、当前品牌官方参考覆盖多少商品，以及高级推荐是否受资格控制。

这些指标描述数据目录，不代表商品安全、功效成功率、用户满意度或商业效果。

### 成分避雷覆盖的含义

4 个成分避雷资格不等于 4 个商品都拥有完整配方：

- 完整列表可检查显式命中，并在未命中时按当前代码放行；
- 关键成分列表只对品牌明确 `official_formulated_without` 的项目放行；
- 关键列表未列出的项目保持未知；
- 当前系列参考商品没有成分避雷资格。

### 敏感肌与功效覆盖的含义

敏感肌和功效资格来自当前品牌官方页面声明。页面与推荐理由必须保留“当前品牌官方参考/品牌官方称”的归属，不将其解释为独立验证、历史配方事实或零风险保证。

## 6. 当前排序分的可解释范围

基础检索分包含：

- 样本价与预算；
- 关键词命中；
- 具体目标功效命中；
- 品牌偏好；
- 偏好成分与肤质适配；
- 是否有关联当前官方参考；
- 历史热度。

最终推荐分再融合 `efficacy`、`sensitivity`、`ingredientTransparency`、`value`、`popularity` 和 `reviewSignal`。

`efficacy` 对未核实商品可能包含由标题标签数量产生的低权重启发值。它只是 UI/排序指数，不能作为核实功效。普通功效需求是软相关性；只有用户明确要求官方/核实功效时，才同时检查 `recommendation_eligibility.efficacy` 和每个具体目标功效。

## 7. 当前自动测试

自动测试实际覆盖三个层面：

### 商品快照清洗

- 标题活动词清洗；
- 完全重复行删除；
- 同商品取最新记录；
- 缺失历史信号保持 `null`；
- 无官方参考时标记 `historical_title_only`。

### 销售工作簿清洗

- 混合日期格式；
- 数量和单价后缀提取；
- 重复、异常日期和孤儿商品处理；
- 聚合数量与金额；
- 不输出客户编码和订单编码。

### 发布数据契约

- 3,497 个商品且主键唯一；
- `metrics.dataset.products` 与目录行数一致；
- 恰有 5 个 `official_current_reference`；
- 不暴露快照日期、客户编码或订单编码；
- 清洗标题不含已移除的活动词；
- `price_label` 为“样本价”；
- 六个指数有限且位于 0–1；
- 敏感肌资格商品具有官方参考和来源。

### 意图、约束与联网来源

`tests/agent.test.ts` 与 `tests/web-search.test.ts` 当前有 17 个回归用例，覆盖：

- 洗面奶/洁面乳/洗颜、散粉/蜜粉与精华水的规范化；
- “不要…换成…”“不要…只要…”及跨品类排除；
- 品牌与成分在不同短句中的正负极性；
- 预算上限、下限、范围和不限预算；
- 中文数字预算、跨叶子品类并列需求与宽类目映射；
- 豆包大类与本地叶子品类映射；
- 护手、身体、洗护发、防晒、口红及目录不存在的口腔/家居分支；
- 核实功效必须匹配具体功效；
- paraben 与 methylparaben 成分族；
- 肤质进入排序；
- 品牌官网域名白名单与第三方页面降级。
- 服务端商品身份白名单，以及联网摘要不提升敏感肌、成分或功效硬资格。
- 基础品类/预算需求不消耗搜索额度，证据型或未枚举类型需求才触发联网。

## 8. 当前未自动验证

以下项目尚无自动测试，不能写成已验证能力：

- `/api/intent` 与 `/api/search` 的请求长度、重试、超时和所有路由降级分支；
- 使用真实 `ARK_API_KEY` / `WEB_SEARCH_API_KEY` 的豆包与搜索上游自动联调；
- Function Calling 字段抽取准确率；
- 桌面和移动浏览器交互回归；
- Figma 与实现截图的像素对比；
- manifest 哈希或构建时间；
- 监管备案、浓度、禁限用目录或 `medical_red_flag` 等医疗风险。

## 9. 人工验收建议

当前发布前应人工检查：

1. `.env.local` 有 Key 与无 Key 两种路径；
2. 预算缺失时进入预算澄清；
3. 敏感肌、功效和成分避雷需求只返回有相应资格的商品；
4. 关键成分记录对未知避开项不放行；
5. 豆包搜索开通时可返回来源，关闭或超时时保留本地结果；
6. 第三方页面即使标题含“官方”也不能提高敏感肌或成分避雷资格；
7. 推荐理由明确写“当前跨市场官方参考”或“联网公开来源”，不反推历史版本；
8. 桌面 Top 3、移动单卡、最多三项对比和三类证据展开保持原交互；
9. Git diff 不含真实 Key、源数据或客户/订单记录。

## 10. 解释限制

- 100% 样本价完整率只说明清洗输出非空，不表示价格仍有效。
- 91.3926% 历史信号覆盖不表示当前销量或真实口碑。
- 5 条官方参考不代表全部 3,497 个商品被核实。
- 资格计数不代表产品对所有人安全或有效。
- 当前启发式排序没有真实相关性标签，不声明推荐准确率或商业提升。
